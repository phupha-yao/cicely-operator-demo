# Demo walkthrough — bus franchise (about 6 minutes)

The data is synthetic, generated by `scripts/demo-story.ts`, and the header says "Illustrative
data". Say so up front.

**Setup:** `supabase start`, `npm run demo:generate`, `npm run dev`. Sign in at
http://localhost:8081. Set `DEMO_ORG_NAME` in `.env` to put the prospect's name in the header.

## 1. Overview: the problems table

- **KPIs:** answers, riders, footfall, problem reports, severe, open issues.
- **Problems by location:** one row per location × problem, showing:
  - when it happens (hour strip, Mon–Fri / all week);
  - which group is behind most of the reports;
  - the report rate;
  - ▲ marks for the conditions it's more common in: rain, dark, disruption, works, busy, late
    buses.
- Read across three rows:
  - **Stand group B:** no audio announcements; blind and partially sighted riders; weekday
    evenings; busy hours and late buses.
  - **Hospital stops:** no seats or shelter; rain ▲ 14×.
  - **Market Square:** hard to find the stand; works ▲.
- Filter by **Problem** or **Group** to re-scope everything.

## 2. Click a row: Stand group B

- **KPIs** for that location and problem.
- **Daily:** reports with rain, temperature, footfall, buses on time, and disruption/works lanes on
  one time axis.
- **Hour × weekday:** the outlined block is 16:00–19:00, Mon–Fri.
- **By stand:** spread across all six stands.
- **By group:** blind and partially sighted riders against everyone else.
- **Recent reports:** individual answers, with the conditions at the time and the rider's
  comment.

## 3. Context

Network-wide daily lanes, and reports by station on one scale. Then the conditions table (rate
inside vs outside each condition) and the list of disruption and works events.

## 4. Issues

1. Under **Detected, no owner**, click **Assign owner** on Stand group B and log it.
2. **Resolved:** the west entrance's step-free reports went from **6.0% to 0.2%** of answers
   after the dropped kerb.

## Reset after a demo

`npm run demo:generate` rebuilds everything, including issues logged during the demo. Allow a
minute for the server's cache, or restart `npm run dev`.
